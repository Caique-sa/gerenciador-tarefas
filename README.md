# Gerenciador de Tarefas (modo terminal)

Esse é um projeto simples em Python que fiz pra começar a me familirizar com a linguagem e com o GitHub.Nele você pode criar, listar, concluir e remover tarefas direto pelo terminal. As tarefas ficam salvas num arquivo `.json`, então mesmo que você feche o programa, elas continuam lá.


# O que usei aqui

- Python 3
- Módulo `json` pra salvar as tarefas
- Módulo `os` pra checar se o arquivo já existe


# Como rodar esse projeto

1. Clone o repositório digitando o comando no terminal:

git clone https://github.com/Caique-sa/gerenciador-tarefas.git

2. Acesse a pasta digitando o comando no terminal:

cd gerenciador-tarefas

3. Rode o programa digitando o comando no terminal:

python main.py

# O que da pra fazer com esse programa?

- Adicionar uma nova tarefa
- Ver a lista de tarefas
- Marcar uma tarefa como feita
- Remover uma tarefa da lista
